# MyPets visual milestone — original paw charm

A lightweight low-polygon paw charm now joins the decorative interactive Three.js toys. It reacts to the existing toy tap and floats only when animations are enabled. In reduced-motion mode the ornaments become static.

**Original illustrations are authoritative and unchanged:** no pet image, 2D animal SVG, photo, or Tripo approval registry was replaced. This is new procedural Three.js geometry, *not* a Blender render or a rigged animal. The scene retains its animation-off and WebGL-unavailable fallbacks. No external services, credentials, credits or unreviewed assets.

Review on mobile: animal art remains visible, tap toys, reduced-motion and animation pause, GPU/WebGL fallback, touch accessibility, and PWA offline shell. GitHub Actions capacity failures are documented separately from successful QA.
