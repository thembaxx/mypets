# Nuzzle

**A little care. A lot of love.**

Plan daily pet care, reminders and species-specific enrichment with Nuzzle. Keep profiles, care history and an optional offline companion on your device.

The repository name `mypets` is an implementation identifier; the public name is **Nuzzle**. Keep the existing wordmark, icon and visual directions. `lib/brand.ts` holds the name, positioning, features, scope and sources used by search metadata and public documentation. Saved-data keys remain stable.

Voice: warm, calm and species-neutral; use practical care language and avoid medical promises. Keep factual, descriptive search titles separate from the expressive tagline.

Forest green, ivory and apricot support the existing two-form Nuzzle mark. Pippa and Kindred stay exploratory studio directions.

Discovery defaults to the verified production origin `https://mypets-pi.vercel.app`. Set `NEXT_PUBLIC_SITE_URL` before building to change it; an explicit empty value omits canonicals and sitemap URLs and marks pages noindex. Use an HTTP(S) origin with no path, query, fragment or credentials.

Public endpoints: `/about/`, `/about.md`, `/robots.txt`, `/sitemap.xml`, `/llms.txt`, `/llm.txt` (same index), `/llms-full.txt` and a 1200×630 `/social.png` card. These contain public product information only. LLM files describe the app; they do not control crawler access or guarantee citations.
